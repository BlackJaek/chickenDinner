# 인스타그램 공식 API 연결하기

자동 수집은 인스타그램 **공식 Graph API의 Business Discovery** 기능을 써요. 비공식 크롤링이 아니라서 계정이 정지될 걱정이 없고, 무료예요.

## 무엇을 볼 수 있나

- **프로페셔널 계정**(비즈니스/크리에이터)인 다른 계정의 소개글, 팔로워 수, **최근 피드 게시물(캡션·링크·날짜)**. 공구를 하는 인플루언서와 브랜드는 대부분 프로페셔널 계정이에요.
- 볼 수 없는 것: 개인(일반) 계정, 스토리, 하이라이트, 친한친구 전용 글, 댓글로만 공지하는 일정
- 호출 한도: 대략 시간당 200회. 기본 설정은 2시간마다 60회씩 써요 (`COLLECT_BUDGET`, `COLLECT_INTERVAL_MIN`).

## 준비물 (한 번만, 20~30분)

1. **내 인스타그램을 프로페셔널 계정으로 전환**
   인스타 앱 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 (크리에이터 또는 비즈니스). 서브 계정을 하나 만들어 써도 돼요.
2. **페이스북 페이지에 연결**
   페이스북에서 페이지를 하나 만들고(비공개여도 됨), 인스타 설정 → 계정 센터에서 그 페이지와 연결해요.
3. **Meta 개발자 앱 만들기**
   https://developers.facebook.com/apps → 앱 만들기 → 유형 "비즈니스"(또는 "기타 → 비즈니스") → 제품에서 **Instagram Graph API(페이스북 로그인 방식)** 추가.
4. **토큰 발급** (Graph API 탐색기: https://developers.facebook.com/tools/explorer)
   - 앱 선택 → 권한 추가: `instagram_basic`, `pages_show_list`, `pages_read_engagement`, `business_management`
   - "Generate Access Token" → 로그인·페이지 선택 후 승인
   - 짧은 토큰을 **장기 토큰(60일)** 으로 바꾸기: 액세스 토큰 디버거(https://developers.facebook.com/tools/debug/accesstoken) → "Extend Access Token"
5. **내 인스타 계정 ID(IG_USER_ID) 확인**
   탐색기에서 `me/accounts?fields=instagram_business_account{id,username}` 실행 → `instagram_business_account.id` 값 (숫자 17자리 정도)

> 내 앱을 내 계정으로만 쓰는 동안에는 앱 검수(App Review) 없이 개발 모드로 쓸 수 있어요.

## 실행

```bash
IG_USER_ID=1784xxxxxxxxxxx IG_ACCESS_TOKEN=EAAG... npm start
```

- 웹 화면 → **수집 계정 관리** 탭에서 아는 공구 계정을 넣고 **지금 수집**을 누르세요. 이후에는 2시간마다 자동으로 돌아요.
- 또는 명령줄에서 한 번만: `npm run collect -- 계정1 계정2`

## 계정이 계속 늘어나는 방식

1. 추적 계정의 최근 글에서 공구 글을 찾아 공구 목록에 넣어요. 날짜와 가격(또는 마감일)까지 읽힌 글은 바로 게시하고, 애매하면 **검토 대기**로 보내요.
2. 글 속 **@언급**을 후보로 모아요. 인플루언서 공구 글에는 보통 브랜드 계정이, 브랜드 글에는 함께 공구하는 인플루언서들이 언급돼요.
3. 후보 프로필을 확인해 점수를 매겨요. 육아 계정 신호(○○맘, ○개월, 아들/딸…)와 공구 신호(소개글의 "공구 문의", 최근 공구 글 수)가 강하면 **자동으로 추적**하고, 육아용품 브랜드도 허브로 추적해요. 육아와 무관해 보이면 제외하고, 애매하면 **후보**로 남겨요.
4. 브랜드가 "11/13~17 @A, 11/20~24 @B" 같은 **릴레이 공구 일정**을 올리면 줄마다 다음 인플루언서의 예정 공구로 들어가요.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `COLLECT_INTERVAL_MIN` | 120 | 자동 수집 주기(분). 0이면 끔 |
| `COLLECT_BUDGET` | 60 | 수집 1회에 쓸 API 호출 수 |
| `AUTO_TRACK_SCORE` | 5 | 이 점수 이상인 후보는 자동 추적 |
| `AUTO_PUBLISH` | 1 | 0이면 수집한 공구를 모두 검토 대기로 |
| `SEED_SAMPLES` | 1 | 0이면 샘플 데이터를 넣지 않음 (API가 설정돼 있어도 넣지 않음) |

## 토큰 만료

장기 토큰은 60일이 지나면 만료돼요. 만료되면 수집 화면에 "토큰 오류"가 표시되니 4번을 다시 하세요.
