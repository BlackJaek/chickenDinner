# 🍼 아기 공구 모아보기

인스타그램에서 팔로워 대상으로 조용히 열리는 **아기용품·이유식 공구(공동구매)** 를 한곳에 모아,
오늘 날짜 기준으로 **진행중 / 오픈 예정** 공구를 보고, **제품별**·**계정별**로 묶어 볼 수 있는 웹서비스입니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 지금 공구중 | 오늘 진행중인 공구. 오늘·내일 마감은 맨 위에, 나머지는 마감 임박순 |
| 오픈 예정 | 오픈 날짜별로 묶어서 (`3일 후 오픈`) |
| 제품별 | 같은 제품을 A → B → C 인플루언서가 **릴레이로 이어서** 하는 흐름을 타임라인으로. "지금 @A 공구중 → 다음은 @B 11.13 오픈" |
| 계정별 | 인플루언서별 진행중·예정·지난 공구 |
| 공구 제보 | 게시물 **링크 + 본문을 붙여넣으면 날짜·가격·제품명·카테고리를 자동 추출** (해시태그 없는 자유 형식 캡션 대응) |

- **기준 날짜 변경**: 상단 날짜를 눌러 특정 날짜 기준으로 진행/예정 확인
- **★ 관심 계정**: 브라우저에 저장, "관심 계정만" 필터
- **캘린더 구독**: 관심 계정의 공구를 `.ics` 피드로 구글/아이폰 캘린더에 구독 (새 공구가 자동 반영). 카드별 📅 버튼으로 개별 추가
- 검색(제품/브랜드/@계정), 카테고리 필터, 모바일 우선 UI, 다크 모드

## 실행

Node.js 22.13 이상만 있으면 됩니다 (외부 패키지 없음, 내장 `node:sqlite` 사용).

```bash
cd babygonggu
npm start            # http://localhost:3000
npm test             # 파서·API 테스트
```

첫 실행 시 화면 확인용 **가상 샘플 데이터**(실존하지 않는 계정·제품)가 들어가며, 상단 배너의 `샘플 삭제`로 지울 수 있습니다.

| 환경변수 | 설명 |
|---|---|
| `PORT` | 포트 (기본 3000) |
| `ADMIN_TOKEN` | 설정하면 **공개 운영 모드**: 일반 제보는 `검토 대기`로 들어가고, 하단 `관리자`에 토큰을 넣은 사람만 게시·삭제 가능. 미설정 시 개인용(모두 바로 게시) |

## 데이터는 어떻게 모이나

1. **자동 수집 (인스타그램 공식 Graph API)** – 아는 공구 계정 몇 개를 **수집 계정 관리** 탭에 넣으면, 그 계정들의 최근 게시물에서 공구를 모으고 게시물 속 @언급을 따라 **연관 인플루언서·브랜드를 계속 발굴**해요. 브랜드의 "릴레이 공구 일정" 글에서 다음 인플루언서의 예정 공구도 잡아요. 2시간마다 자동으로 돌아요.
   → 연결 방법: [docs/instagram-setup.md](docs/instagram-setup.md)
2. **제보** – 스토리나 개인 계정처럼 API로 못 보는 공구는 링크와 본문을 붙여넣어 30초 만에 등록해요.

## 구조

```
babygonggu/
├─ src/server.js        HTTP 서버 + REST API + 정적 파일
├─ src/db.js            SQLite 저장소, 검증, 제품/계정 묶기
├─ src/seed.js          가상 샘플 데이터 (실행일 기준 상대 날짜)
├─ public/              프론트엔드 (바닐라 JS, 빌드 불필요)
│  └─ lib/              서버·브라우저 공용: 캡션 파서, 날짜/상태 계산, ics 생성
├─ src/collector.js     공구 수집 + 연관 계정 발굴
├─ src/instagram.js     Graph API(Business Discovery) 클라이언트
├─ scripts/collect-instagram.js   수집 1회 실행 (cron용)
└─ test/                node:test 테스트
```

### API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/deals?status=ongoing\|upcoming\|ended\|active\|all&q=&category=&date=&handles=` | 공구 목록 (status, dday 계산 포함) |
| GET | `/api/products`, `/api/influencers` | 제품별/계정별 묶음 (그룹 안에 전체 이력) |
| GET | `/api/calendar.ics?handles=a,b` | 캘린더 구독 피드 |
| POST | `/api/parse` | 캡션 → 구조화 정보 |
| POST | `/api/deals` | 제보 |
| PATCH/DELETE | `/api/deals/:id` | 게시·수정·삭제 (관리자) |

상태 규칙: `시작일 > 오늘` 예정, `마감일 < 오늘` 종료, 그 외 진행중. 마감일 미정은 시작 후 14일까지 진행중으로 봅니다. 날짜는 한국 시간 기준입니다.

## 체험판 (서버 없이 브라우저에서)

`public/demo-api.js`가 `/api/*` 요청을 브라우저 안에서 처리하는 체험판이에요. 같은 규칙(`public/lib/core.js`)을 쓰고, 데이터는 그 브라우저에만 저장돼요.

```bash
node scripts/build-demo.js   # demo/index.html 생성 → public/의 styles.css, app.js, demo-api.js, lib/*.js와 함께 정적 호스팅
```
